# CloudVault

A secure, local-first cloud storage platform.

## Setup

1.  **Database**: Run `docker-compose up -d` to start PostgreSQL.
2.  **Run**: `./mvnw spring-boot:run`
3.  **API**: Access endpoints at `http://localhost:8080/api`

## Features

- User Authentication (JWT)
- File Upload/Download/Delete
- Folder Management
